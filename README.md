# Power-Bi-Dashboard--Blinkit

This project focuses on analyzing Blinkit's sales performance using an interactive dashboard developed in Microsoft Power BI. It provides insights into total sales, average sales, number of items, customer ratings, outlet performance, item categories, and outlet characteristics.

The dashboard helps understand sales trends and compare outlet performance to support data-driven business decisions.

Key Performance Indicators (KPIs)
The dashboard highlights the following key metrics:

Total Sales: $1.20M
Average Sales: $141
Number of Items: 8,523
Average Rating: 3.9

Dashboard Features

1. Sales Performance Analysis
Displays total sales and average sales.
Tracks sales by outlet establishment year.
Highlights sales trends over time.
2. Fat Content Analysis
Compares sales of Low Fat and Regular products.
Visualizes the contribution of different fat-content categories to total sales.
3. Item Type Analysis
Analyzes sales across product categories, including Fruits and Vegetables, Snack Foods, Household, Frozen Foods, Dairy, and others.
Identifies categories contributing significantly to overall sales.
4. Outlet Analysis
Compares sales by outlet location tier: Tier 1, Tier 2, and Tier 3.
Analyzes sales distribution by outlet size: Small, Medium, and High.
Compares total sales, item counts, average sales, ratings, and item visibility across outlet types.
5. Interactive Filters
The dashboard includes filters for:

Outlet Location
Outlet Size
Item Type

These filters allow users to explore sales performance across different outlet and product segments.

Tools & Technologies
Microsoft Power BI Desktop — Dashboard development and visualization
Power Query — Data cleaning and transformation
DAX — Measures and KPI calculations, where applicable
Data Visualization — Interactive charts, KPI cards, and tables
Blinkit Sales Dataset — Sales and outlet analysis
